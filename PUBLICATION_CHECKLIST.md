# Publication checklist (manual checks required)

- [ ] Confirm contributor permissions apply to all included collaborative code, diagrams, screenshots, and Unity assets.
- [ ] Verify whether the avatar model, FBX, animations and other third-party material may be redistributed publicly.
- [ ] Review any included screenshots and text for identifying information.
- [ ] Check the **original private Git commit history** for Firebase configuration files, API keys, credentials, private data, and derived datasets. The ZIP cannot show Git history.
- [ ] Do not transfer the original repository history into the new public repository.
- [ ] Verify the actual build / run steps on a clean development machine; this edition intentionally lacks source-derived landmark sequences.
- [ ] Ask UCL BSL SignBank for written clarification before distributing any derived landmark files.

This ZIP is a *candidate* for a public portfolio repository, **not a security audit or confirmation of legal permission**.
